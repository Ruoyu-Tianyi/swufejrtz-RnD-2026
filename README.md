## 发布录取名单

打开 `public/index.html`，搜索 `"admissions"`。在页面末尾 `site-data` JSON 中：

1. 在 `admissions.candidates` 中填写已确认的录取人员，每条记录包含 `name`（姓名）和 `track`（录取方向）。
2. 填写 `publishedAt` 公示时间；`message` 可填写后续安排，留空使用默认欢迎文案。
3. 将 `published` 改为 `true`，保存并推送到 `main`。

当前录取结果尚未公布，名单为空。请使用有效 JSON，记录之间用英文逗号分隔。不要把未公开数据提前写入 HTML；页面内嵌数据可通过源码读取。

同一 JSON 的 `event` 是日期、地点等活动信息，顶层 `candidates` 是面试安排。若改动活动规则，也应同步更新正文、FAQ 与静态表格。
